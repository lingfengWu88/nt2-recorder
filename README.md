# NT2 本地分题录制 — 0.4.14

适用于 Chrome 116+。扩展录制 NT2 播放器中央白色问题卡片（包括其中的题目、图片、进度/录音控件及卡片空白区域），排除顶部标题/题号栏和底部题号导航，并将每道题保存为独立 WebM 文件。视频留在本机，不上传。

## 录制流程

1. 打开受支持的 NT2 播放页面并进入一道正在进行的题目。
2. 确认页面上恰好有一个可访问的 VOLGENDE 按钮，且它当前处于禁用状态。
3. 打开扩展，设置文件名前缀和起始编号，点击“开始录制”。
4. 当 VOLGENDE 从禁用变为启用并持续 1 秒时，扩展会结束并保存当前题目；短暂 UI 状态变化不会触发分段。
5. 保存完成后，扩展重新确认 VOLGENDE 唯一且仍可点击，再自动点击进入下一题并开始下一段。也可以由用户手动点击。
6. 最后一题的页眉为“Vraag N van N”、VOLGENDE 不存在或禁用且 INLEVEREN 可用并持续 1.5 秒时，扩展结束并保存最终题目，然后关闭当前播放器标签页。扩展不会点击 INLEVEREN 或提交答案。
7. 点击“停止并保存当前段”可随时结束。未完成的片段会用 `_partial` 后缀保存。

文件保存在“下载/NT2-recordings/批次时间/”。录制期间保持电脑唤醒，并让目标标签页保持打开。录制后请回放核对题目边界、声音和完整性。

## 自动选口语题并开始

1. 打开官方 Opdrachten oefenen 题目选择页，并从该标签页打开扩展。Chrome 的 tabCapture/activeTab 授权属于用户启动扩展的当前标签页；从新标签页或其他站点启动时，授权不能转移到后来打开的官方页面。扩展会在导航之前立即获取并消费标签页流 ID，预先保持捕获流，但此阶段不保存视频。后续播放器导航必须保留同一标签页和网站来源（origin）。
2. 选择 Programma I Spreken 或 Programma II Spreken，以及题型。扩展会记住这两个筛选项；先设置项目，等待官网更新题型选项，再设置题型，确认两项值后点击 Zoek。
3. 点击“选择全部匹配题目并录制”。扩展会搜索筛选结果的所有页面，并选中匹配条件下的全部题目；官网确认选择数量正确后，才会按官网 Start。
4. 播放器流程中扩展跳过声音示例，直接点击 Geluid is goed 和 Volgende；随后点击 Opname is goed、Volgende，然后在 Start 页再次点击 VOLGENDE。捕获流已在导航前准备好；进入 Vraag 1 后扩展重新计算裁剪区域，并从既有流自动开始分题录制，不会再次请求 stream ID。
5. 如果 Chrome 请求麦克风权限，需在浏览器权限提示中允许。扩展不会更改系统权限设置。若任一页面或按钮不符合预期，流程会停止并在扩展状态中提供可见页面/控件诊断。

自动化仅操作指定的官方 NT2 练习选择页与 Facet 播放页，使用官网正常可见的筛选器、按钮和题目列表；不调用隐藏接口或绕过访问限制。
此自动向导仅适用于包含声音/麦克风检查步骤的 Spreken（口语）练习；Schrijven（写作）练习请使用官网手动流程。
官网每场最多允许选择 100 道题。如果筛选结果超过 100 道，扩展会自动分批启动多场练习；每场最后一题保存后，扩展在同一标签页加载下一批，文件编号连续。完成全部匹配题后状态会报告总数。

## 安装或更新

在 `chrome://extensions` 开启“开发者模式”，使用“加载已解压的扩展程序”选择包含 `manifest.json` 的文件夹。已有安装则先停止录制，再重新加载扩展并刷新播放器页面。

## 边界与错误处理

- 仅支持指定 NT2 官方域名；不会绕过登录、访问限制或 DRM。检测到题目结束并保存完成后，只会点击页面上重新确认的唯一 VOLGENDE 按钮。
- VOLGENDE 和 INLEVEREN 必须能通过可见按钮文字、无障碍标签等方式在页面 DOM 中识别；VOLGENDE 还必须有可读的原生 disabled 或 `aria-disabled` 状态。如果播放器使用扩展无法访问的跨域框架、canvas 或其他不可读控件，录制会报错停止；不会尝试绕过限制。
- 画面裁剪依赖播放器 DOM 中可识别的中央白色问题卡片和页眉/页脚边界。扩展无法定位安全内容卡片时会拒绝启动，而不是录下整页。
- 自动点击 VOLGENDE 后会开始下一段，但实际页面/音频切换可能有延迟，因此片段可能包含短暂过渡。请先用少量题目验证。
- 不录麦克风。WebM 是实际保存格式；VLC 或 Chrome 可播放。
- 视频流、编码或下载失败时会更新状态并停止录制。标签页音轨单独结束时会提示并继续录制画面，等待 VOLGENDE 状态；浏览器强退或断电可能丢失尚未保存的当前片段。

当前实现尚未在真实播放器上完成端到端验证；请先试录并确认控件状态确实可被检测。

## 权限与数据

activeTab/scripting 用于用户主动启动的工作流；受限 host permissions 仅覆盖 NT2/Facet 官方域名；tabs 用于识别练习启动后的播放器标签页；tabCapture/offscreen 用于当前标签页画面声音录制；downloads 保存本地视频；storage 保存设置和运行状态。无遥测、上传或远程代码。

仅录标签页，不录麦克风。保持电脑唤醒并让目标标签页保持打开。浏览器强退或断电可能丢失尚未保存的当前片段。请先试录少量题目并回放检查。
