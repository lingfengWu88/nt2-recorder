适用于 Mac 上的 Chrome 116+。不需要 OBS、Python、开发者付费账号或服务器。
这是浏览器扩展，不是 iPhone App。所有视频保存在电脑的下载文件夹，不上传。

## 安装

1. 解压 ZIP，保留 `nt2-recorder` 文件夹。
2. Chrome 地址栏输入 `chrome://extensions`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择含 `manifest.json` 的文件夹。
4. 在 Chrome 工具栏的拼图菜单中固定“NT2 本地分题录制”。

## 先试录一道题

1. 打开 https://nt2-oefenomgeving.facet.onl/facet-openbaar-portaal/oefenen/opdrachten ，选择 Programma II Spreken，并进入实际练习页面。不要在题目列表页面开始录制。
2. 将浏览器窗口调大，确保题目内容完整可见。扩展只录网页可见区域，不录浏览器工具栏和其他应用，不自动滚动。
3. 点扩展，题数设为 1；每题秒数先设得充足（如短题试 90 秒，实际需要校准）。播放和下一题按钮文字均先留空。
4. 点击“开始录制”，关闭弹窗，立即在网页中播放第一题。如果题目打开后已经播放过，请先回到可重播状态，否则会漏开头。
5. 时限到自动保存；也可再次点扩展，点“停止并保存当前段”。提前停止的文件带 `_partial` 标记。
6. 在“下载/NT2-recordings/批次时间/”找到 WebM，用 VLC 或 Chrome 回放，检查画面、完整声音和题目边界。

## 两题校准，然后再批量

1. 观察网页实际的“下一题”按钮，填写其完整文字或无文字按钮的无障碍名称。扩展不会猜按钮。
2. 如每题需要点“播放”，填其完整按钮文字。留空表示第一题手动播放，后续题目必须会自动播放。
3. 点“检查按钮”。这只检查是否唯一、可点击，不会翻题。如果下一题按钮需等答题结束才启用，先等到启用再检查。
4. 返回第一题开始前，题数设为 2，秒数覆盖说明、准备、答题和按钮启用所需时间。
5. 试录两题并逐段检查。第二段在点击下一题前就开始录制，因此会含上一题画面及约 2 秒过渡，避免漏掉下一题开头的声音。
6. 确认成功后同题型每批 5–20 题；不同题长分批校准。文件以自选前缀和编号命名，不会自动提取题名；起始编号可手动续接。

## 自动化边界

- 采用固定时长，不检测题目、音频或考试阶段结束。不能用一个时长可靠覆盖所有题型。
- 不自动进入题库、选题或选下一批；用户先在官网选好练习题。
- 下一题找不到、按钮被禁用、匹配多个、保存失败都会停止；不是盲目继续点坐标。
- 不支持多步确认、跨域嵌套框架按钮、shadow DOM 内按钮或切到新的标签页。若官网按钮无法识别，先停止批量，把按钮截图和页面地址提供给开发者继续适配。
- 无法保证点击一定使题目切换：网页可能忽略脚本点击，或每题需要另一个操作。两题试录必须核对不重复、不漏题。
- 录制期间保持电脑唤醒、Chrome 窗口和目标标签页在前台；不操作练习页面、不缩放窗口、不锁屏、不让电脑睡眠。
- 不录麦克风；只有标签页声音。取得音轨不等于页面实际有声音，必须回听。
- 停止会保存当前片段；关闭 Chrome、强退或断电可能丢失当前未完成片段。已下载文件不受影响。
- 下载保存要等浏览器确认完成，最多等 60 秒。若启用了“下载前询问每个文件保存位置”，请及时处理提示，或在正式批量前按个人偏好调整此设置。
- WebM 是实际输出格式，不伪装为 MP4。VLC 可以播放；需要 MP4 时再另外转换。

## 权限与数据

activeTab/scripting 用于用户主动选择的页面及按钮；tabCapture/offscreen 用于标签页画面声音录制；downloads 用于保存本地视频并检查下载完成；storage 保存参数和任务状态。无全站访问权限、无遥测、无上传、无远程代码、无外部依赖。只允许从指定 NT2 官方域名开始录制。

制作依据：Chrome 官方 tabCapture 与 offscreen 录制文档：
https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture
https://developer.chrome.com/docs/extensions/reference/api/tabCapture
